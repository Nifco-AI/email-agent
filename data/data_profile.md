# 数据说明

- 来源：本项目编写的虚构数据 `data/emails.json`，1 个文件、5 条邮件。
- 字段：`id`、`sender`、`subject`、`body`，均为字符串；id 唯一。
- 涵盖招聘机会、会议待办、老板请求、广告、普通通知，各 1 封。
- 邮件无接收时间字段；正文明确日期在 2026-10-18 至 2026-10-21。
- 无候选人个人资料。广告含恶意指令文本，只作为数据。
- `mock_results.json` 是手写固定预期结果，不是模型推理记录。
- 最后核对：2026-10-15；使用 Python json.load 与离线测试核对结构及数量。
